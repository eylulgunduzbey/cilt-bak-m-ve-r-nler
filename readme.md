# 🌿 DermAtlas - AI Destekli Cilt Bakım & İNCİ Analiz Rehberi

Bu proje, açık erişimli veri kaynakları ve modern web teknolojileri kullanılarak geliştirilmiş interaktif bir cilt bakımı ve ürün analiz platformudur.

## 🔓 Açık Erişim (Open Access) Entegrasyonu
Bu projede açık veri kaynağı olarak **[Open Beauty Facts API](https://world.openbeautyfacts.org/)** kullanılmıştır. Barkod sorgulamaları ile ürün bileşenleri (INCI) çekilmektedir.

## 🚀 Öne Çıkan Özellikler
- **Keşfet:** Popüler ürün listesi.
- **Barkod Tarama:** Open Beauty Facts API entegrasyonu.
- **Sabah/Akşam Karşılaştırma:** Cilt ürünü katmanlama rehberi.
